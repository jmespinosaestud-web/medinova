# MediNova

Proyecto web académico para organizar medicamentos, recordatorios y citas médicas. Incluye un panel principal, un catálogo de productos de referencia y una página informativa del proyecto.

## Autor
Matías Espinosa

## Tecnologías
- HTML5
- CSS3
- JavaScript

## Páginas
- `index.html`: panel principal de MediNova.
- `pagina2.html`: catálogo, buscador, filtro y carrito de demostración.
- `pagina3.html`: información y objetivos del proyecto.

## Publicación
Cuando GitHub Pages esté activado, agrega aquí el enlace público del sitio.

## Aviso
Proyecto académico. No sustituye la orientación de profesionales de salud. El acceso y las compras del catálogo son demostraciones locales y no constituyen un sistema comercial real.
